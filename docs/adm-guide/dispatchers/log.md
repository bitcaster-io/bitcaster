# Log Dispatcher

The Log dispatcher is a simple dispatcher that writes notifications to the internal log database.
It is mainly used for testing and debugging purposes.

## Configuration

This dispatcher does not require any configuration.

## How to use

1.  Select `Log` as dispatcher for a Channel
2.  Save the Channel.

Now you can add this channel to your Application and send notifications. The notifications will be visible in the Log section of the administration panel.
