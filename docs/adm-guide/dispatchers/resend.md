# Resend Dispatcher

The [Resend](https://resend.com/) dispatcher sends notifications via Resend's API.

## Configuration

The following parameters are required to configure the Resend dispatcher:

- **API Key**: Your Resend API Key.

## How to use

1.  Select `Resend` as dispatcher for a Channel
2.  Fill the form with your Resend API Key.
3.  Save the Channel.

Now you can add this channel to your Application and send notifications.
