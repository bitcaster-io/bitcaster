# Postmark Dispatcher

The [Postmark](https://postmarkapp.com/) dispatcher sends notifications via Postmark's API.

## Configuration

The following parameters are required to configure the Postmark dispatcher:

- **Server Token**: Your Postmark Server Token.

## How to use

1.  Select `Postmark` as dispatcher for a Channel
2.  Fill the form with your Postmark Server Token.
3.  Save the Channel.

Now you can add this channel to your Application and send notifications.
