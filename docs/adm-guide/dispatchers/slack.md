# Slack Dispatcher

The Slack dispatcher sends notifications to a Slack channel via an incoming webhook.

## Configuration

The following parameter is required to configure the Slack dispatcher:

- **URL**: The Slack incoming webhook URL. You can create one in your Slack workspace settings.

## How to use

1.  Select `Slack` as dispatcher for a Channel
2.  Fill the form with your Slack incoming webhook URL.
3.  Save the Channel.

Now you can add this channel to your Application and send notifications to the configured Slack channel.
