# Mailjet Dispatcher

The Mailjet dispatcher sends notifications via Mailjet's API.

## Configuration

The following parameters are required to configure the Mailjet dispatcher:

- **API Key**: Your Mailjet API Key.
- **API Secret**: Your Mailjet API Secret.
- **From Address** (optional): The email address used as sender. Falls back to the channel's sender email if not set.
- **From Name** (optional): The name displayed as sender.

## How to use

1.  Select `Mailjet` as dispatcher for a Channel
2.  Fill the form with your Mailjet API Key and API Secret.
3.  Save the Channel.

Now you can add this channel to your Application and send notifications.
