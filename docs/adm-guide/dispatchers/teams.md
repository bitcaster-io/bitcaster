# Microsoft Teams Dispatcher

The Microsoft Teams dispatcher sends notifications to a Teams channel via an incoming webhook.

## Configuration

The following parameter is required to configure the Microsoft Teams dispatcher:

- **Webhook URL**: The Incoming Webhook URL from Microsoft Teams channel configuration. You can create one in your Teams channel settings.

## How to use

1.  Select `Microsoft Teams` as dispatcher for a Channel
2.  Fill the form with your Teams incoming webhook URL.
3.  Save the Channel.

Now you can add this channel to your Application and send notifications to the configured Teams channel.
