# Brevo Dispatcher

The [Brevo](https://www.brevo.com/) dispatcher sends notifications via Brevo's API.

## Configuration

The following parameters are required to configure the Brevo dispatcher:

- **API Key**: Your Brevo API Key.

## How to use

1.  Select `Brevo` as dispatcher for a Channel
2.  Fill the form with your Brevo API Key.
3.  Save the Channel.

Now you can add this channel to your Application and send notifications.
