# Mailgun Dispatcher

The [Mailgun](https://www.mailgun.com/) dispatcher sends notifications via Mailgun's API.

## Configuration

The following parameters are required to configure the Mailgun dispatcher:

- **API Key**: Your Mailgun API Key.
- **Sender Domain**: The domain you have configured in Mailgun for sending emails.

## How to use

1.  Select `Mailgun` as dispatcher for a Channel
2.  Fill the form with your Mailgun API Key and Sender Domain.
3.  Save the Channel.

Now you can add this channel to your Application and send notifications.
